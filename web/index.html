Channel codes Appendix 1
The folder prefix column is what this tool actually writes.
CodeFolder prefixChannelPlatform
The spec describes the prefix as “3-digit channel code + 2-digit platform”, but several Appendix 1 codes already contain the platform token (SGYT, IFCYT) while others do not (IEC, IUC). The Folder prefix column reproduces both of the spec’s own examples (SGYT→SGYThin, IEC→IECYThin).

Twelve regional languages have no ISO 639-2 code, so their ISO 639-3 code is used (brx, hne, tcy, grt, kfy, gbm, bgc, bhb, kfa, kru, lbj, mwr). Reference: loc.gov/standards/iso639-2
The naming rules
Every rule the checker enforces.
1Only hyphens - and underscores _ are allowed as separators.
2No spaces anywhere in a folder or file name.
3No special characters: , . % ' ( )
4Every letter after a hyphen or underscore is capital.
5Language code is exactly 3 lowercase letters — except categories #4 and #7, which capitalise it (Tel).
6Dates are dd-Mmm-yyyy, e.g. 09-Jul-2021.
7The video code comes from the English URL, never the regional one.
8The Video Output folder is mandatory inside the main folder.
9The published MP4 must start with Output. Never IG_Output — Archives rejects it.
