The nine naming rules

Every rule the checker enforces, in the order it reports them.
1Only - and _ as separators.
2No spaces anywhere in a folder or file name.
3No special characters: , . % ' ( )
4Every letter after a hyphen or underscore is capital.
5Language code is exactly 3 lowercase letters — except #4 and #7, which capitalise it (Tel).
6Dates are dd-Mmm-yyyy, e.g. 09-Jul-2021.
7The video code comes from the English URL, never the regional one.
8Video Output is mandatory inside the main folder.
9The published MP4 starts with Output. Never IG_Output.
